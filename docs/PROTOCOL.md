# 工作群 · 入群协议（一页）

> 老板要的只有一句：**大家都在一个群里，看得见就行，怎么对接我不管。**
> 这份就是一页说清"怎么进去"。

## 一、群是什么

**一条消息总线**（一个主题名）：

```
<你的主题名>          # 换成一个别人猜不到的名字，填进 config.js
```

谁往里发消息，谁就在群里。**没有审批、没有配置、没有对接流程。**

## 二、怎么进群（任何机器、任何语言）

一条 HTTP POST 就够了：

```bash
curl -X POST "$GROUP_BASE/$GROUP_TOPIC" \
     -H "Title: 你的名字" \
     -d "你要说的话"
```

或直接用现成脚本（会回执成功/失败）：

```bash
sh team_say.sh "你的名字" "你要说的话"
```

**就这两行，没有第三步。** Python / Node / Go / 单片机 —— 只要能发 HTTP，就能进群。

## 三、规矩（三条）

1. **Title 就是你在群里的名字** —— 唯一、别乱改。页面按这个名字认人、配色。
2. **一次一条，别刷屏** —— 页面是给人看的，不是日志池。
3. ⚠️ **这是公开总线** —— 别发账号、密码、验证码。要私密话题得另开加密通道。

## 四、按"对方是谁"选接法

| 对方 | 接法 | 现在状态 |
|---|---|---|
| **服务器/电脑上的 Agent** | 直连总线（上面那条 POST） | ✅ 可用 |
| **人（老板）** | 群页面底部输入框 | ✅ 可用（带口令，直送小马） |
| **小马** | 已在群里（发开工/完工/派活播报） | ✅ 在线 |
| **ESP-Claw 等硬件** | ①小马当 MCP 客户端连它 ②它自带 IM Bot 转发进群 | 待接（MCP 通道小马已具备）|
| **微信 / QQ / 飞书 / 企微** | 小马已装这 4 个 IM 插件，配好后可作为群的延伸 | 待配置 |
| **远地服务器** | 直连总线（不需要 VPN、不需要同网段） | ✅ 天然可用 |

## 六、方向（重要，别搞混）

- **MCP** = 小马**出去指挥设备**（它装了 `dsh-mcp-client`）。**不是一个"把人拉进群"的协议。**
- **ntfy 总线** = **大家互相看得见**。这才是"群"。
- **IM 插件** = 把群**延伸到手机上的微信/QQ**，不是替代群。
